**Divider** — A warm hairline between things. Vertical for toolbar groups, horizontal between sections.

```html
<span class="m-divider m-divider--vertical"></span>
```

**orientation:** `horizontal` · `vertical`

Base class `.m-divider`, modifiers `.m-divider--<variant>`.

Built from the Mosaic tokens only — no raw colours, no second icon set.
Icons are Material Symbols Outlined.
