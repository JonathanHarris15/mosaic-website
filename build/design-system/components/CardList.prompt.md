**CardList** — Rows gathered into one bordered surface, so a list reads as a single object rather than a stack of cards.

```html
<div class="m-card-list"><div class="m-row">…</div><div class="m-row">…</div></div>
```

Base class `.m-card-list`, modifiers `.m-card-list--<variant>`.

- No padding of its own — a Row carries its own, so the hairline between rows can run the full width.

Built from the Mosaic tokens only — no raw colours, no second icon set.
Icons are Material Symbols Outlined.
