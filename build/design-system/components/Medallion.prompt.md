**Medallion** — The round icon plate on a NavCard. Fills with --primary-fixed when its card is hovered.

```html
<span class="m-medallion"><span class="material-symbols-outlined">folder_open</span></span>
```

**size:** `sm` · `md`

Base class `.m-medallion`, modifiers `.m-medallion--<variant>`.

Built from the Mosaic tokens only — no raw colours, no second icon set.
Icons are Material Symbols Outlined.
