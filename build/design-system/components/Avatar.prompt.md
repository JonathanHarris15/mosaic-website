**Avatar** — A Person's Directory Photo, or their initials when there is none. Framing comes from PersonPhotoCore so the reframing preview and every card agree.

```html
<span class="m-avatar">JH</span>
```

**size:** `sm` · `md` · `lg`

Base class `.m-avatar`, modifiers `.m-avatar--<variant>`.

- Absent and empty are the same thing: no photo means initials, never a placeholder silhouette.

Built from the Mosaic tokens only — no raw colours, no second icon set.
Icons are Material Symbols Outlined.
