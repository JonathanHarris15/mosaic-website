**SearchBar** — An Input with a leading search glyph and a clear button that only appears once there is something to clear.

```html
<div class="m-search"><span class="material-symbols-outlined">search</span><input placeholder="Search people" /></div>
```

Base class `.m-search`, modifiers `.m-search--<variant>`.

Built from the Mosaic tokens only — no raw colours, no second icon set.
Icons are Material Symbols Outlined.
