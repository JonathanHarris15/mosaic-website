**EmptyState** — What a list says when it has nothing in it. An icon and one calm line inside a dashed container — never italic grey text, which reads as an apology for a state that is usually normal.

```html
<div class="m-empty"><span class="material-symbols-outlined">event_busy</span><p>Nothing on this week yet.</p></div>
```

Base class `.m-empty`, modifiers `.m-empty--<variant>`.

- There were 23 italic-grey empty states across nine pages, against a rule the design system had already written down.

Built from the Mosaic tokens only — no raw colours, no second icon set.
Icons are Material Symbols Outlined.
