What sits below the query

Iteration stays in the Query block (lists of people, Sundays, events). Under it, the drawer offers shape: single inserts: a live date (today, offset, or fixed), the page number (optional custom start), and brand assets — upload images or fonts for this printable, see what is on file, drag onto the canvas. Not data-repeat.
