API Key

The Textbelt key is stored server-side as a Firebase secret and is never exposed to the browser. Set or rotate it from a terminal:

firebase functions:secrets:set TEXTBELT_KEY

Then redeploy functions for the new key to take effect.

schedule_send

Automatic sending

When on, the hourly scheduler texts each upcoming service's pastoral-prayer subjects automatically (5 days out, with a 3-day reminder, 8am–8pm Central). When off, only the manual "Send now" button in the Service Builder sends.

These are the texts sent when we ask people for a prayer request before a service. Use {name} where the person's first name should appear (it falls back to "there" if unknown).

The same asks, on a lock screen. A title past characters is cut off on the phone — the count is there so that is visible before it is saved. Use {name} in the title and the body. The elder digest stays a text; it is not a lock screen.

history

Sent history

One row per attempt, newest first, in the church's own clock. A send skipped for the quiet hours writes nothing at all — it is not a failure, it is a send that has not happened yet.

Outbound texts sent before the log was renamed may still only exist in sms_messages. Nothing here reads or changes that collection; copying it across is a deliberate one-off, not something this page does.

devices

Devices & tokens

A device token is the handle one signed-in phone is reachable at. Only its owner may read one, so these arrive through an admin-only function and are masked to their last six characters before they leave the server. The whole token is never sent to this page.

phonelink_ring

Send a test push to myself

Pushes to the devices signed in as you, and to nothing else. The server reads your own account and ignores anything this page could name, so there is no way to aim it at somebody else — and no send-to-everyone control anywhere on this tab. The send is logged like any other, under admin_test_push.
